# Invoicing Guide

Detailed steps to create invoices, manage line items, apply adjustments, track payments, and export PDFs.

[!NOTE]
If you don’t see Invoicing in the sidebar, you may not have permission. Contact an administrator.

## 1. Overview

Invoicing turns approved timesheets and contract terms into billable documents. Use this module to compile line items, generate PDFs, and track payment status.

### Who uses it
- Finance: create invoices, post adjustments, record payments
- Project Managers: review draft invoices for accuracy
- Administrators: oversee configuration (rates, templates, permissions)

## 2. Prerequisites

- Approved timesheets for the billing period
- Correct services and rate templates linked to projects/contracts
- Valid client/company data in Organizations

[!TIP]
Confirm approvals in Timesheets before starting to avoid discrepancies.

## 3. Create a New Invoice

1. Open Invoicing and click “New Invoice”
2. Select projects and date ranges
3. Review automatically compiled line items based on services and approved hours
4. Edit descriptions, quantities, or rates if needed (role-permitting)
5. Save the draft

### Line item details
- Description: service name or activity
- Quantity: hours/units
- Rate: per-hour or per-unit rate
- Amount: calculated total (quantity × rate)
- Notes: optional explanations or references

## 4. Adjustments & Credit Notes

- Use adjustments to correct billing after posting or to handle negotiated changes
- Create a negative line item (credit) to offset previously billed amounts
- Document the reason in notes for audit clarity

[!WARNING]
Adjustments affect financial dashboards. Record them carefully with clear notes.

## 5. Payment Tracking

- Open an invoice → Payment panel
- Record payment date, amount, method, and reference
- Status updates: Draft → Sent → Partially Paid → Paid
- Use partial payments where applicable; amounts roll up in dashboards

## 6. PDFs & Exports

- Generate and download invoice PDFs
- Include cover pages or attachments if your process requires
- Store PDFs in your document repository for auditing

## 7. Common Workflows

- Standard billing cycle:
  1. Verify approved timesheets
  2. Create invoice and check line items
  3. Generate PDF and send
  4. Record payments as received

- Post-invoice corrections:
  1. Create adjustment (credit or debit)
  2. Note reason and link to original invoice

## 8. Troubleshooting

- Missing line items: ensure timesheets are approved and services are correctly linked
- Incorrect rates: review project contracts and rate templates
- Partial payment mismatch: verify recorded amounts and dates
- PDF won’t generate: refresh, then retry; check templates if applicable

## 9. FAQs

- Can I edit posted invoices?
  - Use adjustments rather than editing posted invoices.

- How do taxes or fees apply?
  - If configured, they are added as line items or calculated fields.

- Can I combine multiple projects into one invoice?
  - Yes, select multiple projects when creating the invoice.

## 10. Best Practices

- Keep services and rates aligned with contracts
- Review draft invoices with project managers
- Record payments promptly with references
- Use adjustments for audit-friendly corrections
