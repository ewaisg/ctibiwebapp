# Shortcuts & Accessibility Guide

Be faster and more inclusive with built-in shortcuts and accessible design.

## 1. Command Palette

- Press ⌘K to open the command palette
- Type to search actions and pages; hit Enter to execute

## 2. Common Shortcuts

- ⌘K: open command palette
- Esc: close dialogs or menus
- Tab/Shift+Tab: move focus forward/backward

[!TIP]
Open the Keyboard Shortcuts dialog in the app to see full mappings.

## 3. Keyboard Navigation

- Skip-to-content link appears when focused for quick navigation
- Focus styles are consistent and visible
- Use arrow keys in menus and lists where supported

## 4. Screen Readers

- UI components use semantic roles and labels where available
- Announcements appear for key updates (e.g., toasts)

## 5. Focus Management

- Dialogs trap focus until closed
- Modals and menus return focus to the trigger after closing

## 6. Troubleshooting

- Can’t reach a control: try Tab/Shift+Tab or reset focus
- Focus lost after action: press Tab to re-engage; report persistent issues

## 7. FAQs

- Where can I learn all shortcuts?
  - Open the Keyboard Shortcuts dialog or use ⌘K and type “shortcuts”.

- Can I customize shortcuts?
  - Not currently. Use the command palette to speed up navigation.

## 8. Best Practices

- Prefer keyboard for repetitive tasks
- Report any accessibility obstacles with page URL and steps
- Keep your browser updated for better accessibility support
