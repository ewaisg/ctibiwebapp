# Projects Guide

A comprehensive guide to managing projects, teams, services, contracts, files, and related workflows.

[!NOTE]
If you don’t see Projects in the sidebar, you may not have permission. Contact an administrator.

## 1. Overview

Projects represent client work with timelines, budgets, contracts, resources, and deliverables. This module is the hub for planning, tracking, and billing.

### Key capabilities
- Create and edit projects
- Assign team members and define their roles/rates
- Link services and contracts to ensure proper billing
- Manage project files and templates
- Track progress via dashboards and reports

## 2. Access & Roles

- Administrators: full access (create/edit/delete, assignments, services/contracts)
- Project Managers: create/edit projects, manage team and allocations
- Finance: view projects, confirm contract terms and billing details
- Staff: view assigned projects and related files

[!TIP]
Use ⌘K to open the command palette and jump to Projects, Assignments, or Files quickly.

## 3. Creating a Project

1. Open Projects from the sidebar
2. Click “New Project”
3. Enter details:
   - Name: descriptive title
   - PO Number: purchasing order (must be unique)
   - Client/Company: who the project is for
   - Start/End Dates: planned timeline
   - Department/Division: organizational alignment
   - Notes: scope or constraints
4. Save — you can edit later

[!IMPORTANT]
PO Number is used as a stable identifier; choose carefully and avoid duplicates.

## 4. Project Fields Explained

- Project Name: visible on dashboards and invoices
- PO Number: unique ID for cross-module references
- Client/Company: ties to the Organizations module
- Dates: used for allocations, timesheet grouping, invoicing periods
- Services: billable services associated with the project
- Contracts: contractual terms and rate references
- Team Assignments: who is working and at what rate/role
- Files: documents and templates stored under the project

## 5. Team & Resource Allocations

- Open the Team/Assignments tab within a project
- Add members:
  - Search employees by name or ID
  - Set role (e.g., Engineer, Analyst) and rate
  - Define start/end dates for the assignment
- Update or remove assignments as needed

### Best practices
- Always define roles and dates to ensure accurate utilization and invoicing
- Keep rates aligned with contracts and pay items

## 6. Services & Contracts

- Services: specific billable activities (e.g., development, analysis)
- Contracts: legal terms and agreed rates

To link services and contracts:
1. Open Services/Contracts tab
2. Add services relevant to the project scope
3. Select or create the contract and ensure rate templates match

[!NOTE]
Correct service and contract setup ensures invoice line items are accurate.

## 7. Files & Documents

- Use Project File Manager to upload, preview, and organize files
- Supported: common office files and PDFs
- View PDFs in-app using the built-in PDF Viewer

### Tips
- Keep templates updated and labeled by version
- Use folders or naming conventions for clarity

## 8. Importing Projects (Optional)

If bulk import is enabled:
1. Go to Project Import
2. Download the latest template (CSV/XLSX)
3. Fill required fields (e.g., name, PO number, client)
4. Upload and review validation results
5. Fix any errors and re-upload

[!WARNING]
Always start from the latest import template to avoid formatting issues.

## 9. Dashboards & Reports

- Project dashboard shows progress, staffing, and financial highlights
- Drill down from widgets to see detailed allocations and timesheets
- Export PDFs for packet summaries or status reports

## 10. Common Workflows

- Start a new project:
  1. Create project with PO number and client
  2. Set timeframe and notes
  3. Add team assignments and rates
  4. Link services/contracts
  5. Upload initial documents

- Update staffing:
  1. Add/remove assignments when team changes
  2. Adjust dates/rates to reflect new terms

- Prepare for invoicing:
  1. Ensure services and contracts are correct
  2. Confirm timesheets are approved for the billing period

## 11. Troubleshooting

- Can’t create project: check permissions or missing required fields
- Duplicate PO number: pick a unique PO number; edit existing project if needed
- Incorrect rates in invoices: review services/contracts and pay items
- Missing assignments in utilization: verify start/end dates and active status

## 12. FAQs

- Why is PO number important?
  - It uniquely identifies the project across modules and invoices.

- Can I change the PO number?
  - Avoid changing after invoicing starts. If necessary, coordinate with Finance.

- How do services affect invoices?
  - Services link billable activities to rate templates, forming invoice line items.

## 13. Best Practices

- Establish clear naming and coding conventions for projects
- Keep assignments current; end-date inactive allocations
- Align services/contracts with finance policies
- Use project files to keep key documents centralized

## 14. Glossary

- Assignment: a person’s role and time allocation on a project
- Services: billable activities associated with a project
- Contract: legal and financial terms for billing
- Utilization: measure of how staff time is allocated and billed
