# PDF Viewer & Documents Guide

Work with reports and document packets inside the app.

[!NOTE]
If you don’t see the PDF viewer, open a report/packet from Projects, Timesheets, or Invoicing.

## 1. Overview

The built-in PDF viewer lets you open, navigate, zoom, and download reports without leaving the app.

## 2. Viewing Features

- Page navigation: next/previous and page jump
- Zoom controls: fit-to-page, fit-to-width, custom zoom levels
- Search (if enabled): find text within the PDF
- Thumbnails (if enabled): preview and jump to pages

## 3. Tools

- Download: save the PDF to your device
- Print (if enabled): send to a printer
- Open in new tab (if provided): use browser viewer

[!TIP]
Use fit-to-width for large tables; switch to fit-to-page for overall layout.

## 4. Annotations (Planned)

- Future enhancements may include notes, highlights, and stamps
- For now, use external tools if annotation is required

## 5. Troubleshooting

- PDF doesn’t load: refresh the page; check network connection
- Viewer tools disabled: feature may be restricted; download instead
- Text not searchable: source PDF may not contain text (image-only)

## 6. FAQs

- Can I edit the PDF?
  - No, the viewer is read-only. Download to edit externally.

- Why can’t I print?
  - Printing may be restricted by policy. Download and print if allowed.

## 7. Best Practices

- Keep important reports downloaded for reference
- Verify totals and signatures on official documents
- Use consistent naming when saving files
