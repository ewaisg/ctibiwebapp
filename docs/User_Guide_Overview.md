# CTI BI User Guide – Overview

Generated: 2025-11-12

CTI BI is a business intelligence web application for CTI operations. It helps teams manage projects, timesheets, invoicing, and reporting in one place.

[!NOTE]
This guide is for end users. No technical knowledge required.

## Quick Start Checklist

1. Sign in — you’ll land on the Dashboard
2. Press ⌘K to open the command palette
3. Review your role-based modules in the sidebar
4. Upload timesheets or open your projects
5. Check dashboards and approve entries where needed
6. Generate invoices and download PDFs if your role permits

## Navigation Tips

- Use ⌘K to jump to modules and actions
- Filters help focus dashboards and lists
- Drilldowns from widgets take you to details

## Who is this for?
- Administrators: manage users, organizations, and settings
- Finance: build invoices, track payments, run reports
- Project managers: manage projects, teams, contracts
- Employees: upload timesheets, view assignments

## What can I do?
- See key KPIs on the dashboard
- Manage companies, departments, employees, projects, and contracts
- Upload and review timesheets
- Generate invoices and track payments
- View and download PDF reports

## Getting started
1. Sign in and you’ll be redirected to the Dashboard
2. Use the left sidebar to access modules
3. Press ⌘K to open the command palette for quick navigation
4. Open the Keyboard Shortcuts in the help menu to discover time savers

## Modules
- Dashboard: high-level metrics and quick links
- Projects: create and manage projects, assignments, and files
- Timesheets: upload and review timesheet data
- Invoicing: generate invoices and track payments
- Manpower & Utilization: resource and capacity insights
- Organizations: companies, departments, divisions, contracts
- Employees & Users: employee records and user access
- Admin & Settings: system configuration and permissions
- Profile & Account: personal details and session
- Documents & PDFs: view and export reports
