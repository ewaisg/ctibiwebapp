# Employees & Users Guide

Manage employee records and user access with clear roles and permissions.

[!NOTE]
If you don’t see Employees or Users in the sidebar, you may not have permission. Contact an administrator.

## 1. Overview

Employees represent people in the organization, with roles, rates, and department mappings. Users are login accounts with permissions determined by roles.

### Who uses it
- Administrators: manage user accounts and roles
- HR/Operations: maintain employee records
- Managers: review staff details for project planning

## 2. Employees

### Create or edit
1. Open Employees
2. Click “New Employee” or select an existing one
3. Fill fields:
   - Employee ID (unique)
   - Name and contact
   - Role/Title and department
   - Rate and employment type
   - Notes
4. Save

### Import (optional)
- Use Employee Import with the latest template (CSV/XLSX)
- Correct validation errors and re-upload

## 3. Users

### Create user accounts
1. Open Users
2. Click “New User”
3. Link to an employee (recommended)
4. Set email and initial role
5. Save — user receives sign-in instructions if configured

### Roles & Permissions
- Roles determine what a user can see and do
- Common roles:
  - Admin: full access
  - Finance: invoicing/payment capabilities
  - Manager: projects, assignments, approvals
  - Staff: timesheets and assigned project views

[!WARNING]
Grant roles with least privilege. Review permissions before changes.

## 4. Workflows

- New hire onboarding:
  1. Create employee record
  2. Create linked user account
  3. Assign initial role and department

- Role changes:
  1. Review access requirements
  2. Update user role
  3. Confirm with manager/finance

- Offboarding:
  1. End-date employee assignments
  2. Disable user account
  3. Archive records as needed

## 5. Troubleshooting

- Duplicate Employee ID: choose a unique identifier
- Missing access: ensure a user account exists and role is set
- Wrong permissions: update role; sign out/in to refresh

## 6. FAQs

- Do all employees need user accounts?
  - Only those who sign in. Others can exist as records without access.

- Can I link multiple users to one employee?
  - Avoid unless necessary; keep one user per employee for audit clarity.

- How quickly do role changes take effect?
  - After sign-out/in or token refresh.

## 7. Best Practices

- Maintain accurate employee departments and roles
- Use clear naming and stable IDs
- Apply least privilege and review access periodically
- Link users to employees for better reporting and audits
