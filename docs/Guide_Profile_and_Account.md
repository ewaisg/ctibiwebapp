# Profile & Account Guide

Manage your personal details, preferences, and session.

## 1. Profile

- View and update display name and basic information
- Some fields may be locked by your administrator

## 2. Preferences

- Theme: switch between light, dark, or system
- Notifications: toast messages appear for key actions
- Keyboard: open the Keyboard Shortcuts dialog to learn quick actions

[!TIP]
Press ⌘K to open the command palette and navigate faster.

## 3. Session & Security

- Sign out from the user menu when finished
- If your access changes, sign out and back in to refresh permissions
- Use strong passwords and avoid sharing accounts

## 4. Troubleshooting

- Profile changes not saving: check required fields and connection
- Missing access after role update: sign out/in to refresh tokens

## 5. FAQs

- Can I change my email?
  - Contact an administrator if the field is locked.

- How do I reset my password?
  - Use the forgot password flow on the sign-in page, if available.

## 6. Best Practices

- Keep your profile info current
- Learn shortcuts to speed up daily tasks
- Sign out on shared devices
